# HAUNTED INTERNET — школьный проект о дипфейках

Полностью русскоязычный интерактивный сайт для проекта по информатике в 10 классе. Дизайн вдохновлён мрачной underground-эстетикой, цифровыми помехами, ночным лесом и кислотно-зелёными акцентами.

## Файлы

- `index.html` — структура и текст сайта.
- `style.css` — оформление, адаптивность и анимации.
- `script.js` — интерактивный тест, чек-лист, лаборатория и финальный сценарий.

## Как запустить локально

Открой `index.html` в браузере. Для обычного просмотра дополнительная установка не нужна. Шрифты загружаются из Google Fonts; если они недоступны, сайт использует системные запасные шрифты.

## Как опубликовать через GitHub Pages

1. Создай новый репозиторий на GitHub, например `haunted-internet`.
2. Загрузи в корень репозитория файлы `index.html`, `style.css`, `script.js` и этот `README.md`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. В качестве ветки выбери `main`, папку `/ (root)`, затем нажми **Save**.
6. Через некоторое время GitHub покажет ссылку на опубликованный сайт в разделе Pages.

## Важно

- Это учебный симулятор, а не автоматический детектор дипфейков.
- В тесте специально есть ситуации, где правильный ответ — «недостаточно данных».
- Сервисы в разделе инструментов открываются на внешних сайтах.
- Сайт не собирает и не отправляет пользовательские данные.
- Если проект будет оцениваться учителем, добавь на страницу имя автора, класс и название школы по желанию.
